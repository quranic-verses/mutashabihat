# متشابهات القرآن الكريم

اختبار يومي في متشابهات القرآن: يظهر موضع متكرر مع عدد تكراره وعدد السور، واللاعب يكتب أسماء السور.

- `index.html` — اختبار اليوم: في أي سورة ورد هذا الموضع؟ (+ التدريب على الأجزاء المحفوظة)
- `farq.html` — فرّق بينهما: موضعان متشابهان يختلفان في كلمة أو كلمتين، فاعرف سورة كل منهما (222 اختبارًا، الاختبار ١ يوم 3 أكتوبر 2026) + التدريب على الأجزاء المحفوظة
- كل البيانات (2,384 موضعًا) داخل نفس الملف
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — التثبيت على الهاتف والعمل بدون إنترنت
- `privacy.html` — سياسة الخصوصية (عربي + English)، مطلوبة لمتجر Google Play
- `og-image.png` — صورة المعاينة عند مشاركة الرابط

الاختبار يتغير تلقائيًا كل يوم عند منتصف الليل بتوقيت القاهرة لكل اللاعبين. الاختبار رقم ١ هو يوم 2 أكتوبر 2026.
