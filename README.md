# متشابهات القرآن الكريم

ثلاثة اختبارات يومية في متشابهات القرآن الكريم، مع التدريب على الأجزاء المحفوظة:

- `index.html` — أين ورد؟: موضع متكرر وعدد تكراره، واللاعب يكتب أسماء السور التي ورد فيها
- `kalima.html` — لم تتكرر: ثلاث كلمات، واحدة منها فقط وردت في القرآن مرة واحدة، واللاعب يختارها (٣ جولات كل يوم) (الاختبار ١ يوم 3 أكتوبر 2026) + التدريب
- `farq.html` — ميّز بينهما: موضعان متشابهان يختلفان في كلمة أو كلمتين، فاعرف سورة كل منهما (822 اختبارًا، الاختبار ١ يوم 3 أكتوبر 2026) + التدريب على الأجزاء المحفوظة
- كل البيانات داخل نفس الملف: 2,461 سؤالًا في «أين ورد؟» و822 في «ميّز بينهما»
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — التثبيت على الهاتف والعمل بدون إنترنت
- `privacy.html` — سياسة الخصوصية (عربي + English)، مطلوبة لمتجر Google Play
- `og-image.png` — صورة المعاينة عند مشاركة الرابط

الاختبار يتغير تلقائيًا كل يوم عند منتصف الليل بتوقيت القاهرة لكل اللاعبين. الاختبار رقم ١ هو يوم 2 أكتوبر 2026.
