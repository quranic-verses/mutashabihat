# متشابه اليوم

لغز يومي في متشابهات القرآن: يظهر موضع متكرر مع عدد تكراره وعدد السور، واللاعب يكتب أسماء السور.

- `index.html` — لغز اليوم: في أي سورة ورد هذا الموضع؟ (+ التدريب على الأجزاء المحفوظة)
- `farq.html` — فرّق بينهما: موضعان متشابهان يختلفان في كلمة أو كلمتين، فاعرف سورة كل منهما (222 لغزًا، اللغز ١ يوم 3 أكتوبر 2026)
- كل البيانات (2,384 موضعًا) داخل نفس الملف
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — التثبيت على الهاتف والعمل بدون إنترنت
- `og-image.png` — صورة المعاينة عند مشاركة الرابط

اللغز يتغير تلقائيًا كل يوم عند منتصف الليل بتوقيت القاهرة لكل اللاعبين. اللغز رقم ١ هو يوم 2 أكتوبر 2026.
